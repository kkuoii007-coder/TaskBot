# 📋 TaskBot — Telegram-бот для управления задачами

**TaskBot** — это Telegram-бот для небольших команд (до 50 человек), позволяющий эффективно управлять задачами, отслеживать их статус, назначать исполнителей и получать уведомления о приближающихся дедлайнах.

## Возможности

- ✅ Создание задач с приоритетом, дедлайном и исполнителем
- ✅ Отслеживание статуса: новая → в работе → выполнена
- ✅ Просмотр личных и командных задач
- ✅ Экспорт задач в CSV-файл (совместим с Excel)
- ✅ Автоматические напоминания о дедлайнах (ежедневно в 09:00)
- ✅ Удобное меню через Telegram
- ✅ Валидация формата даты при создании задачи

## Стек технологий

| Компонент | Технология |
|---|---|
| Язык | Python 3.11+ |
| Telegram | aiogram 3.x |
| База данных | SQLite3 (aiosqlite) |
| Планировщик | APScheduler 3.10+ |
| Зависимости | pip |

## Быстрый старт

### 1. Установка

```bash
# Клонируйте репозиторий
git clone <repository_url>
cd taskbot

# Создайте виртуальное окружение
python -m venv .venv

# Активируйте окружение
.venv\Scripts\activate  # Windows
source .venv/bin/activate  # Linux/Mac

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка

```bash
# Скопируйте шаблон .env
copy .env.example .env  # Windows
cp .env.example .env    # Linux/Mac

# Откройте .env и вставьте токен бота от @BotFather
```

### 3. Запуск

```bash
python main.py
```

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и главное меню |
| `/help` | Список всех команд |
| `/add` | Создать задачу (пошаговый диалог с валидацией) |
| `/list` | Все активные задачи команды |
| `/my` | Ваши задачи |
| `/done` | Отметить задачу выполненной (бот запросит ID) |
| `/cancel` | Отменить задачу (бот запросит ID) |
| `/status` | Изменить статус через inline-кнопки (бот запросит ID) |
| `/delete` | Удалить задачу (бот запросит ID, автор — всегда, другие — 1 час) |
| `/list_csv` | Экспорт всех задач в CSV |
